# 🚀 MERN Portfolio Website

A modern and fully responsive **Portfolio Website** built using the **MERN Stack** with an **Admin Dashboard**, **Real-Time Notifications (Socket.io)**, and a secure authentication system. This portfolio allows dynamic management of projects, skills, experience, and contact messages without modifying the source code.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

### Install Dependencies

Frontend

```bash
cd frontend
npm install
```

Backend

```bash
cd backend
npm install
```

---

## 🔑 Environment Variables

Create a **.env** file inside backend.

```env
PORT=5000

MONGO_URI=your_mongodb_url

JWT_SECRET=your_secret_key

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

CLIENT_URL=http://localhost:5173
```

Backend
